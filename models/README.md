# 模型存档

每个阶段的关键模型。`.pt`、`.npz` 文件用 Git LFS 存储，克隆后要先运行 `git lfs pull` 才能拿到。用 `tools/export_model.py` 生成新条目，它会去掉优化器状态和本机路径，导出一份不依赖 pickle 的纯数组版本，并附上评估结果和导出的按键录像。

成绩指原版 2002 物理、从出生点起、智能体全程操作，温度 0.3。第 1 关的上榜线为 92.999 s，精品线 83.499 s，TAS 74.457 s。

每个第 1 关模型目录里都带着它观测用的参考线 `refpaths/L01.npz`，检查点已指向它，克隆并 `git lfs pull` 之后，目录本身就能用 `scripts/eval_m2.py --ckpt` 运行（还需要原版游戏、BML+ 0.3.12 和 BallrainIO 模组）。这条线第 1 小节的一段捷径取自 BallanceMMO 公测中人类玩家最快 5 次成功通过的平均几何。
