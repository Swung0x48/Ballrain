# L2 南环：东侧双轨南端（v1）

**不是缺一块路，是没有及时消掉向南的速度。先改静止起点菜单，不改线、不放宽 stall。** 同一石球从 1618 起步，一直按南到首次越过 1780，再切闭环，两个构建都过盘；只把切换点延到 1782，两版都从弯外掉下。两次首次过 1780 的位置和速度相同（水平速率 13.80）。因此不存在仅凭入弯速率即可判死活的阈值。

## 入弯动作、速度与支撑

以下均为 `local_s`，世界坐标，负 x 向西、负 z 向南。v1、TAS 帧 14730、真实 rest reset，各条件每版一次；时间为交接后游戏秒（帧/132）。**速度表用引擎 `speed + speed_change` 的物理秒口径**；本段用轨迹位移除游戏秒约为其两倍。`episodes.csv.speed` 则是映射后净进度 / 游戏秒；题中的约 4 不是瞬时入弯速度。

**最快实测通过**（首次 `s≥1780`）：两版均 **13.89**，即约 27.8 世界米/游戏秒；从 1618 充分加速，1770 时 13.62，1780.44 时 `(vx,vz)=(−3.60,−13.42)`，之后收向 8，1790/1800/1810 时为 7.82/7.97/7.85。目标上限 40 不等于实速 40。这是已证下界，不是引擎极限。上述延迟对照中切在 1782/1784/1786/1790 均失败：**无需在南向直轨预先刹停，但不能把南键一路带过弯心**，轨道本身也会带出西速。

从活动线球心每 0.25 m 查静态碰撞三角形最近点：1766 附近由 `A03_Rail_02` 接 `A03_Rail_03`；**1780–1810 全是 `A03_Rail_03` 的弯曲双轨及其西向延段**，不是从轨端跳到木板。线到网格 1.991–2.011 m（石球半径 2），安全实跑该段球心离线最多 0.040 m。不要把双轨中缝的单根竖直射线当无支撑。无需重画线；保留 r8 的 v1 pin `f7faf3cf9c9621f55f6c0de3f56dd6c2813a0cec33ca22672cbd6c4ba8e9649b`。若改成员字节才需 learner 重新 pin 并分发，客户端跟随所发包。
