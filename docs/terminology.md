# Ballance 术语对照

中文文字（网页、报告、文档）里的 Ballance 专用名词，统一用 Ballance 中文社区 wiki（ballance.jxpxxzj.cn）的说法。
代码里的标识符、日志字段、英文文档不受影响。

| 概念 | 用 | 不用 | 备注 |
|---|---|---|---|
| checkpoint（点燃后开始下一小节的火盆） | **盘点** | 检查点 | wiki 正式词条名是“存档点”，“盘点”是它的别名，两者都对；本项目统一写“盘点”。开局的四团火叫“起始盘点” |
| sector（两个盘点之间的部分） | **小节**，第 N 小节，X-Y（如 1-1） | 段、扇区、区段 | |
| level | **关卡**，第 N 关 | | |
| airship（终点） | **飞船** | 飞艇、气球 | 第 12、13 关结束接木球的是“飞碟”，是另一个东西 |
| 完成一关 | **通关** | | |
| spawn | **出生点**；球“出生” | 关卡起点（指出生点时） | |
| respawn point / 重生 | **重生点**、**重生** | 复活、复活点 | |
| 死亡 / 掉下去 | **死亡**、**死球** | 掉落、掉球、摔死 | 判定是球与死亡区（DepthTestCubes）相交 |
| death zone | **死亡区** | 死亡盒 | |
| trafo | **变球器**（木球变球器 / 石球变球器 / 纸球变球器，简称木变 / 石变 / 纸变）；动作叫“变球” | 变压器、trafo（中文文字里） | |
| 变球时的碎块 | **碎片** | | |
| fan | **风扇** | 鼓风机、通气机 | |
| 球的种类 | **木球 / 石球 / 纸球**；玩家操控的球叫**球**或**玩家球** | 木头球、石头球 | |
| 场景里的 P_Ball_* | **道具球** | 场景小球 | |
| score ball | **分数球**；被吃后跟着球跑的 6 个小球叫**分数小球** | 积分球、追逐小球、小分数球 | 收分：按 Esc |
| extra life | **生命球**；生命数叫**生命**（口语“命”） | 加命球、血 | |
| 关卡里的活动物体 | **机关**（箱子、秋千、推板、软木桥、升降机、跷跷板……） | | |
| rails | **钢轨**（单轨、双轨） | 铁轨 | |
| camera | **视角**（非 90 度视角） | 相机 | |
| shortcut | **捷径**；正常路线叫**标准走法** | 近道、标准路线 | |
| 第 1 关第 1 小节 TAS 的跳跃（原“捷径 2”） | **弯轨捷径** | 捷径 2 | 木球在第一个大平台侧向飞到围墙上，沿围墙到出口钢轨护栏，飞到石变附近 |
| 原“捷径 1”（绕到石变后从左侧鬼躲） | **鬼躲石变**（1-1 木躲石） | 捷径 1 | |
| 1-1 第二个大平台的跳跃 | **贝多芬捷径** | | |
| speedrun | **竞速**；模式名 **SR / HS** | 速通（作正式说法时） | |
| record | **纪录** | 记录（作名词“纪录”时） | |
| community record table | **英雄榜** | 名人堂、hall of fame | |
| 排行榜门槛 | **上榜线 / 精品线** | 加精线 | |
| 一关吃满全部分数球生命球且不死 | **一命全分** | | |

不属于 Ballance 的说法（训练里的“开局点”“课程”“回合”等）不在此表内。模型的 checkpoint 写成“模型检查点”，不要和盘点混淆。
