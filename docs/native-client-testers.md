# Ballrain 算力池客户端测试版：使用说明

感谢参与测试！这个程序用你自己电脑上的 Ballance，在后台用无头引擎跑 AI 的训练对局，把数据传给训练服务器。
不需要安装 Python，也不会改动你的游戏文件。

## 1. 你需要
- Windows 10（1903 或更新）或 Windows 11，64 位。
- 一份 Ballance 游戏（你自己的安装）。客户端只读取安装目录里的 `base.cmo`、`Database.tdb`、`3D Entities`、`Text`。
- 一个 Ballance 论坛（forum.ballance.top）账号。网关会检查账号的注册时间、邮箱是否验证、回复数，不满足时登录页会直接说明原因。

## 2. 安装
1. 下载 `BallrainPool-<版本>-windows-x64.zip`，**完整解压**到一个文件夹（例如 `D:\BallrainPool`）。不要在压缩包里直接双击运行。
2. 双击 `BallrainPool.exe`。

**第一次运行时 Windows 可能会拦下来**（蓝色窗口“Windows 已保护你的电脑”，这是 SmartScreen）：
测试版还没有代码签名，所以会这样。点“**更多信息**”，再点“**仍要运行**”。之后就不会再问。
如果杀毒软件把它隔离了，请把解压的文件夹加入信任，并告诉测试负责人是哪个杀毒软件。

## 3. 首次设置
1. **Ballance 目录**：填你的 Ballance 安装文件夹（里面有 `base.cmo` 的那个），也可以点“查找常见位置”。
2. 点“检查游戏文件”。有问题时会逐项用中文说明（例如“缺少文件夹：Text”）。
3. 点“保存并继续”。

路径里有中文也没关系：这种情况下客户端会把引擎要读的四项游戏文件（约 19 MB）复制到 `C:\ProgramData\BallrainPool`，游戏目录本身不动。

## 4. 登录
点“在浏览器中登录”，浏览器会打开登录页面：用论坛账号登录，核对页面上的登录代码和客户端显示的一致，然后确认。
论坛密码只在浏览器里输入，客户端看不到。登录成功后回到客户端，它会自动进入主界面。

## 5. 主界面
- **开始 / 暂停**：随时可以暂停。暂停时正在跑的那一局会马上结束并上传。
- **实例数 − / ＋**：同时跑几个引擎（默认是 CPU 核数的一半，最多 8 个）。电脑卡的话就减少。引擎都以低优先级运行，不会弹窗口。
- **上榜：开 / 关**：是否在排行榜上显示你的论坛昵称（默认开）。
- 表格里每一行是一个实例：状态、当前任务、步数、已被服务器接收的步数、速度。
- 下面是网关统计（已接收 / 已验证 / 待验证的步数）和日志。

**自动暂停**：你打开 Ballance（Player.exe）玩游戏时，或者笔记本拔了电源用电池时，客户端会自动暂停，结束后自动继续。

**关闭**：点“退出”或直接关窗口都可以。没传完的数据会留在本机，下次打开时接着传。

## 6. 横幅提示是什么意思
屏幕上方的彩色框是网关发来的提示，**原文照登**：
- **网关拒收**（黄色）：某一段数据或请求被拒绝，框里写着原因。偶尔出现一次没关系；一直出现请导出诊断。
- **令牌已停用**（红色）：你的登录被停用了（例如数据校验没通过，或管理员停用），所有实例会停下。框里有原因；需要时重新登录。
- **无法连接**（红色）：连不上网关，或本机设置有问题（框里写着是哪一项）。网络恢复后会自动重连。
- 蓝色的“有新版本”：去提示里的地址下载新的 zip，解压覆盖原来的文件夹即可（数据和登录状态都保留）。

## 7. 遇到问题
点主界面的“**导出诊断**”：客户端先列出要打包的文件和内容，确认后在数据目录里生成 `diagnostics-<时间>.zip`。
里面的令牌、你的用户名和电脑上的路径、论坛账号、IP 地址都已经替换掉了。把这个 zip 发给测试负责人，并说一下发生了什么。

## 8. 你的数据在哪里
- 配置、登录令牌、日志、待上传的数据：`%LOCALAPPDATA%\BallrainPool`（在资源管理器地址栏输入这个路径即可打开）。
- 只有路径含中文时才会用到：`C:\ProgramData\BallrainPool`（游戏文件副本和临时运行目录）。
- 想彻底清除：退出客户端，删除这两个文件夹和解压出来的程序文件夹。

## 9. 常见问题
- **一直显示“空闲”**：服务器暂时没有任务时会这样，稍后会自动取任务。
- **“实例 N 连续 8 次出错，已停止重试”**：多半是游戏文件或引擎有问题。按“开始”可以再试；还不行就导出诊断。
- **电脑变卡**：减少实例数；玩游戏时客户端会自动暂停。
- **能不能在玩 Ballance 的同时跑？** 可以开着，但客户端会自动暂停，等你关掉游戏再继续。
